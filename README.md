# Healthy Me

Healthy Me është një aplikacion web për zakone të shëndetshme ditore.

## Struktura e projektit

- `index.html` — faqja kryesore
- `pages/` — faqet e përmbajtjes, Login dhe Register
- `assets/css/` — stilet e ndara sipas rolit
- `assets/js/` — funksionalitetet JavaScript të ndara sipas rolit
- `assets/images/` — imazhet e projektit

## Teknologjitë

HTML, CSS dhe JavaScript.
