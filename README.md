# HEALTHY

Project for course : "Dizajn dhe Zhvillimi Web" from student Suela Jashari 2026/2027

A small self-care web app built with HTML, CSS, and JavaScript.

## Open the project

Open `index.html` in a browser. A local static server can also be used to serve the `HEALTHY` folder.

## Pages

- `index.html` — home page with a three-message carousel
- `hydration.html` — daily water tracker saved in the browser
- `movement.html` — gentle movement ideas and daily habit checkboxes
- `wellbeing.html` — mood check-in and a breathing exercise
- `login.html` — demo sign-in form
- `register.html` — demo registration form

Every page shares the same responsive navigation and visual styles. Styles are in `assets/css/style.css`; interactive behavior is in `assets/js/app.js`.

## Note

This is a front-end prototype. The forms are not connected to a server or database, and the app does not measure health or provide medical diagnoses. Habit data is stored locally in the browser.
